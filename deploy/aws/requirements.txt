#   numpy / pandas / scipy / networkx / matplotlib : package, experiments, tests
#   openpyxl   : pandas.read_excel of the ACS NTA workbooks (data/raw/acs/*.xlsx, acs_weights.py)

#   pytest     : the test suite (about 480 tests) and the bootstrap toy check
# Not listed on purpose: requests (only data/fetch_counters.py, a one-off download script).
#
# Install on the EC2 instance (Ubuntu 24.04 x86_64, Python 3.12 venv):
#     python3.12 -m venv ~/battery_swap/venv && . ~/battery_swap/venv/bin/activate
#     pip install -r deploy/aws/requirements.txt
#
# torch: on Linux the CPU-only wheel from the PyTorch index (about 190 MB) instead of the
# default PyPI wheel, which bundles CUDA (about 900 MB) and is useless on a CPU instance.
# The "+cpu" local version exists only on that index, so pip cannot pick the CUDA build by
# mistake.  Verified on 2026-10-19: torch-2.9.0+cpu-cp312-cp312-manylinux_2_28_x86_64.whl is
# listed at https://download.pytorch.org/whl/cpu/torch/.  On macOS the plain 2.9.0 wheel is
# installed (there is no "+cpu" build for macOS; the macOS wheel is CPU-only anyway).
